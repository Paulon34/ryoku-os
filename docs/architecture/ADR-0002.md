# ADR-0002 — Temporary lab boot: Linux kernel + Ryoku initramfs seed

- **Status:** Accepted for Mission 008 (Boot Seed) — temporary lab path
- **Date:** 2026-11-07
- **Deciders:** Mission 008

## Context

Mission 007.1 proved the Virtual Lab can observe a **reference** Alpine guest over
serial under QEMU TCG. That validates the harness — it does **not** choose Alpine
(or any other distro) as Ryoku’s definitive userland base (still unformalized per
ADR-0001).

Ryoku now needs a **first-party** early-boot artifact: a minimal init that can run
as PID 1 and announce itself on the serial console, so later missions can claim a
*Ryoku-owned* guest process without pretending a full OS exists.

## Decision

For **lab / Virtual Lab T3 only**, adopt temporarily:

1. **Unmodified Linux kernel** from a **trusted official upstream or previously
   verified lab channel** (see [../testing/boot-seed.md](../testing/boot-seed.md)).
2. **Minimal Ryoku initramfs** whose `/init` is the first-party `ryoku-init`
   binary (Rust), not a third-party distro userspace.
3. **Do not** declare Debian, Alpine, Arch, or Nix as the definitive Ryoku base
   in this ADR.
4. **Do not** vendor Desktop / private nixos trees into this seed.

The boot-seed marker `RYOKU_BOOT_SEED_READY` on guest serial may satisfy
`t3.boot_seed` after an authorized T3 run. That remains distinct from a finished
**Ryoku OS product boot**.

## Alternatives considered

| Option | Why not now |
|--------|-------------|
| Keep only Alpine T2 | Does not exercise first-party PID 1 |
| Full rootfs from a distro | Premature base choice; license/inventory burden |
| Custom kernel fork | Violates “upstream intact first” |
| Claim product boot from init alone | Dishonest — init ≠ OS |

## Consequences

- New crate `zaquion-core/ryoku-init` + initramfs pack script (no root, no host mods).
- Separate QEMU profile `t3-boot-seed` (kernel+initrd), not Alpine ISO T2.
- Kernel blobs stay **out of git**; integrity pins documented before any T3 fetch.
- T3 execution requires **separate authorization** (not part of Mission 008 review stop).
