## Private / non-redistributable

- **ryoku-nixos** wallpapers: repository not accessible from this agent (`404` / denied). Nothing from that tree was published.
- Host-private overlays and personal photos must **not** be committed to GitHub.
- Optional local import (no GitHub):

```bash
ryoku-import-wallpaper /path/to/photo.jpg
# → ~/.local/share/ryoku/wallpapers-private/
```

Settings gallery merges public (`~/.local/share/wallpapers`) and private roots. Private files stay on the machine.
